Guidelines

Usage Rules

전용서체는 모든 그룹에 공통으로 쓰고, 그룹은 컬러로 구분합니다. 사업별 단일 색상의 일관성과 분야별 구분의 유연성을 함께 가져갑니다.

기본 원칙

01

공식 로고는 원본 파일로

서체는 BI 문구, 제목, 브랜드 그래픽 제작용입니다. 로고 자체를 서체로 다시 입력해 대체하지 않습니다.

02

제목·브랜드 문구 전용

간격이 로고 기준으로 조여져 있어 작은 크기의 본문에는 적합하지 않습니다. 부득이한 경우 자간을 넓혀 사용합니다.

03

사내 사용만 허용

폰트 파일을 외부에 전달하거나 외부 서버·공개 저장소에 올리지 않습니다. 협력사 제작물에 필요하면 디자인 파트를 통해 요청합니다.

04

영문·숫자·기호만 수록

한글은 포함되어 있지 않으므로 한글 문구는 기존 지정 서체를 사용합니다.

BI 그룹 컬러

흰 배경 명도 대비 4.5 이상이면 본문 글자까지 사용할 수 있습니다.

서체 설치

  1. 디자인 툴에는 OTF, 오피스에는 TTF를 설치합니다.
  2. PowerPoint·Word에서는 [글꼴] 설정의 "글꼴 커닝"을 켜야 로고와 같은 간격이 적용됩니다.
  3. 합자(fi, fl 등)는 대부분의 디자인 툴과 웹 브라우저에서 자동으로 적용됩니다.

웹 적용 (사내 서비스)

@font-face {
  font-family: "FnGuide Logotype";
  src: url("<사내 CDN 경로>/FnGuideLogotype-Regular.woff")
       format("woff");
  font-display: block;
}
.brand {
  font-family: "FnGuide Logotype", serif;
  font-kerning: normal;
}
