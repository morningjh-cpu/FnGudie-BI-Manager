# 17. 디자인 아티클 — 파비콘·아이콘·오픈그래프 만들기·받기 (계획, 2026-10-29)

## 요청 (사용자 말)
- 로고타입 다운로드 밑에 "디자인 아티클" 항목을 넣어, 로고타입을 이용해 만드는 파비콘·아이콘·오픈그래프 데이터를 생성하고 다운로드하는 페이지를 만든다.
- 정한 것: 메뉴는 독립 메뉴(다운로드와 사용 규칙 사이) / 오픈그래프는 사업 색 배경 + 흰 로고 / 받는 파일은 웹 표준 세트 ZIP
- 아이콘 재료는 피그마 확인 후 계획: https://www.figma.com/design/HFvFpU5By1MzcqHUax8toq/FnGuide-Brand-Management-Service?node-id=4-5306

## 피그마에서 본 것 (페이지 "FnGuide Brand Symbol")
- 04 Icon: 사업 색 네모 + 전용서체 흰 "Fn". 파비콘 16px 4색(빨강·초록·남색·진남색), 아이콘 크기 16·24·32·64·128·256·512
- 6 Symbol Icon: 자체 심볼이 있는 서비스는 심볼로 아이콘 (예: CryptoGuide)
- 01~03: 심볼 있는 서비스 3종 — Retamin(R), DataGuide(DG ∞), CryptoGuide(G 큐브)
- 7 Open Graph: 사업 색 배경 + 흰 전용서체 로고 + 아래 한글 한 줄 소개 (WiseReport "흩어져 있는 투자 정보는 와이즈리포트에서", CryptoGuide "디지털자산 정보 플랫폼"). 600×315 시안 → 1200×630 으로 만듦
- 표지: FnGuide Brand Symbol Design 2026, 별 모양 심볼

## 만들 화면 (index.html, #article)
1. 서비스 고르기: 다운로드 표와 같은 로고 목록·순서
2. 아이콘 미리보기: 기본은 "Fn" 아이콘(그 서비스의 사업 색), 심볼이 있는 서비스(위 3종)는 "심볼 / Fn" 중 고르기. 16·24·32·64·128·256·512 를 실제 크기로 나란히
3. 오픈그래프 미리보기: 사업 색 + 흰 로고 + 한글 소개 한 줄(입력 칸, 피그마에 있는 2종은 기본값 채움)
4. 받기: 개별 PNG·SVG 단추 + "전체 받기(ZIP)"
   - favicon.ico(16·32·48 한 파일), favicon.svg, apple-touch-icon 180, 안드로이드 192·512, 아이콘 7종 크기, og-image 1200×630, 웹페이지에 붙일 코드(head.html)
- 모두 브라우저 안에서 만듦(외부 라이브러리 없음, 기존 ZIP 방식 재사용). "Fn" 글자는 font-data.js 윤곽으로 그림

- 아이콘 받기 단추: favicon.ico · icon.ico(일반 아이콘 16·24·32·48·64·128·256) · SVG · PNG-512px (사용자 요청). icon.ico 는 ZIP 에 넣지 않음(사용자 결정)
