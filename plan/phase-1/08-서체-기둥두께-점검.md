# 08 전용서체 기둥(세로 굵은 획) 두께 점검 (2026-10-27)

## 요청
- 폰트로 만든 로고에서 대문자 I의 기둥이 다른 글자보다 굵어 보임 → 대소문자별로 튀어 보이는 글자를 찾고 수정 방법 제안. (파일 안 숨겨진 내용은 무시)

## 측정 (v1.200 글자 윤곽에서 곧은 세로선 두 개를 짝지어 잼, 35칸 좌표 기준)
- 대문자 기둥 중앙값 4.03: 전부 ±2% 이내. I 4.06(+1%)로 H·E·F·L(4.03)과 사실상 같음. → 숫자로는 I가 굵지 않음
- 소문자 기둥 중앙값 3.75: 새 f·m 4.00(+7%)만 튐. 기존 v1.100에서는 f 3.75, m 3.78이었음 → 이번 업데이트에서 생긴 차이
- 대문자 기둥은 소문자보다 8% 굵음(4.03 vs 3.75). 원래 로고 설계값.
- I 와 이웃 기둥 사이 흰 간격: nI·In 5.56, HI 5.22, nn 4.50 → I 주변이 좁아서 굵어 보이는 것은 아님(오히려 넓은 편)
- 못 잰 글자: N, b (사선·둥근 획과 이어져 곧은 선을 못 찾음)

## 해석
- I가 굵어 보이는 이유(추측): ① 소문자 이웃 기둥보다 8% 굵음 ② 옆에 열린 공간·가로획이 없는 단독 기둥이라 빽빽하게 보임 ③ 깃발 세리프가 작아 기둥만 두드러짐

## 시안 (임시 폴더, 본 파일 아님)
- out/font-update/trial_I15 (I 기둥 3.91, -4%), trial_I30 (3.76, 소문자와 같게) / 비교 그림 out/font-update/compare-I.png
- 두 시안 모두 I 외 글자·간격 규칙은 그대로, I 오른쪽 면만 안쪽으로 이동. 커닝 고정(pin) 단계는 거치지 않은 미리보기용.

## 결정과 반영 (2026-10-27)
- 사용자가 시안 A(I 기둥 4.06 → 3.91, -4%) 선택 → v1.200 본 서체에 반영.
- 반영 방법: I-upper.svg 의 오른쪽 면만 안쪽으로 0.15 이동(옛 파일 보관: out/font-update/I-upper_before-A.svg). 여백·커닝 다시 계산, I 가 바뀐 글자 목록(pin_unrelated.py 의 CH)에 들어가 I 와 관련된 쌍은 새로 계산.
- 검증: 겹침 0쌍, I·f·m·M·s·S·y·f 합자 외 글자는 폭·커닝 v1.100과 동일. I 폭 352 → 347.
- 비교 그림: out/font-update/v1.200/preview/compare-I-applied.png
- f·m 은 아직 결정 대기(디자이너 확인 요청 여부).

## 추가: f·m·r 에 같은 조정 적용 (2026-10-27)
- 사용자 요청: I 에 한 기둥 조정(시안 A, 0.15 ≈ 4% 가늘게)을 새로 들어온 f m r 에도 적용.
- 방법 (`out/font-update/work/thin_stems.py`): 이웃 획과 이어지지 않은 면을 안쪽으로 0.15
  - r: 기둥 왼쪽 면 14.19 → 14.34
  - f: 기둥 왼쪽 면·바깥 곡선 끝 13.18 → 13.33 (f 합자 8종도 같은 수치로 다시 만듦, make_lig_v2.py 의 STEM_L)
  - m: 왼쪽 기둥 바깥 면 +0.15, 오른쪽 기둥 바깥 면 −0.15, 가운데 기둥은 양쪽 0.075씩(안쪽 공간 둘이 고르게)
- 결과: 기둥 4.00 → r 3.88 · f 3.84 · m 3.84 (소문자 3.75 대비 +2~3%, 끝자리는 1000단위 반올림). 폭 f 487 · m 894 · r 430.
- 겹침 0쌍, 바뀐 글자 외 v1.100과 동일. 간격 보정 규칙 1,260 → 1,203.
