# 06 콘텐츠 결정 (05-콘텐츠안 검토 결과)

홈에서의 브랜드 히스토리 연표는 좋은 의견이지만, 데이터가 그다지 좋지 않아서. 안함
전용서체의 합자 미리보기도 실제 사용자 입장에선 크게 와닿는 문제가 아니어서. 안함
다운로드 의견도 안함. 사용규칙의 자주 묻는 질문도 아직 서비스 전이라 운영하고서 일정 시간이 지나야 필요할 것 같아.
다운로드 기록을 남긴다는 것도 제외할게

## 05에서 빠지는 항목
- 홈: 브랜드 히스토리 연표
- 전용서체: 합자·커닝 켜고 끄기 미리보기
- 다운로드: 그룹별 거르기·검색, PNG 크기 선택, 한번에 받기(zip)
- 사용 규칙: 자주 묻는 질문 (운영 후 일정 시간 지나서 검토)
- 사이트 전체: 다운로드 기록(사번·파일·시각)

## 남은 질문 답
1 둘다. 2 진행. 3 진행, 4 진행, 5 안함. 6 진행, 7 업데이트만 하도록하고 게시하지 않음.

- 1 서체 파일 받기: 전용서체 화면과 다운로드 화면 둘 다
- 2 흰 글자(반전) 로고: 만든다 → 로고타입 화면 배경별 보기
- 3 서비스별 출시 연도: 넣는다 (피그마 숨김 메모 기준)
- 4 회사 CI: 리뉴얼 전 옛 로고, 2011 에프앤자산평가 CI 보여준다
- 5 전용서체 남은 일: 공개 안 함
- 6 홈 최근 업데이트 소식: 넣는다
- 7 디자이너용 자료(교정지·점검 보고서): 사이트에 게시 안 함, 자료만 최신으로 관리

## 2차 시안 수정
로고타입 소개의 우측 상단에 있는 각 컬러 칩은 없애줘. 정신 사납다. 작업 끝나면 커밋해줘.
→ 칩 삭제, 색상 코드는 설명 줄("컬러")에 글자로 남김

FnPricing 로고까지 다운로드할 필요는 없을 것 같아.
→ 이전 CI(FnGuide 2000, FnPricing)는 지금처럼 전시만, 다운로드 없음

다운로드 표 로고를 같은 크기로 (칸 맞춤 축소 → 같은 배율). 로고타입 소개 카드도 같은 크기로 맞춰줘.
리타민은 주 색상이 #1C1C3A 이고 보조 색상이 #26C0D2 이야, 추가/변경해줘.
→ 리타민 컬러 배경 판은 주 색상 #1C1C3A, 홈 카드·B2C 화면·배경 조합 표에 주/보조 구분

## 회사 CI 재구성
회사 CI 항목에 이전 CI가 공식로고야. 이부분은 다음 회사 홈페이지의 CIP 부분을 참고해서 보강해줘. 다운로드 가능 추가해줘.
현재 공식로고라고 있는 부분은 개선된 브랜드 로고이지 공식로고가 아니야. 순서상 위치가 뒤바뀌었어
참고: https://corp.fnguide.com/Company/CIP (받은 파일·페이지 사본: data/corp-cip/)

→ 회사 CI 화면 순서: 공식 로고(CI) → 로고타입(FnGuide Inc., (주)에프앤가이드) → 전용색상 → 단도 색상 → 개선된 브랜드 로고(FnRed 2025) → 로고타입 개선 → 그 밖의 CI(FnPricing, 보기만)
→ 공식 CI는 홈페이지 파일 그대로, 흰색·단색 판도 홈페이지 파일만 사용(변형 금지 규정). AI·PNG 원본 zip 받기 추가
→ 회사 CI 색은 홈페이지 전용색상 Fn Red #962E45 / Fn Dark Gray #6B7B84 / Fn Light Gray #A8B0B6 로 표시
※ 확인 필요: 홈페이지 표의 Fn Red RGB(130/0/25)는 HEX #962E45 와 다른 색이고, 로고 파일 실제 색은 #94243A·#778288 임

로고타입 소개의 회사 CI에 쓰인 Fn Red 라는 명칭을 개선된 FnRed와 구분할 수 있도록 Fn Wine으로 변경해줘.
그리고 다운로드에서 FnGuide Inc. 은 제외해주고, 한글 로고타입은 다른 로고와 사이즈 균형이 맞도록 크기를 키워줘. 여기서만 Retamin과 FnAPI 위치를 바꿔줘.
그리고 사용규칙에 B2C 리타민 (주), (보조)를 한 줄에 함께 표시해.
→ 회사 CI 색 이름: Fn Wine #962E45 (홈페이지 표기는 Fn Red), 단색 파일 이름 fnguide-ci-wine

CI 주색상은 #94243A이 맞아. 홈페이지에 표시된게 잘못되었나보네.
→ 회사 CI 색을 #94243A로 통일 (흰 배경 대비 8.16), 색 표 RGB는 HEX에서 계산한 148/36/58로 고침. Pantone·CMYK는 홈페이지 값 그대로(검증 안 됨)

Fn Dark Gray는 #778288 (공식 CI 로고 파일의 회색). 홈페이지 표의 #6B7B84 대신 사용, RGB 119/130/136으로 고침
다시 칠해줘. FnAPI는 일단 대기해줘. 커밋 후에 폰트 디자인을 업데이트 할거야.
→ 단색 Dark Gray 파일을 #778288로 다시 칠함(원본 data/corp-cip 는 그대로, 도구에서 바꿈). FnAPI는 대기
