# 01 — 스킬 적용 리뉴얼 시안 (2026-10-30)

## 사용자 요청
- taste-skill · ui-ux-pro-max · impeccable 스킬을 모두 써서 리뉴얼 디자인.
- 리뉴얼은 별도 폴더 "Apply skills Ver", 맨 위 design-index.html 로 본다.
- 범위: B안 — 홈 + 대표 화면 2~3개 시안 먼저. 전용서체 사용은 유지.

## 만든 것
- design-index.html(맨 위): 새 페이지. 화면 3개 — 홈(#home) · 전용서체(#font) · 로고타입(#logo/그룹, 6개 그룹 모두).
- Apply skills Ver/style.css · app.js: 새 페이지의 모양·동작.
- 서체·로고·심볼·다운로드 파일은 out/brand-site/ 것을 그대로 불러옴(복사 안 함).
- 아직 안 만든 화면(디자인 아티클·사용 규칙·폰트 업데이트·디자인 크리틱)은 기존 index.html 의 해당 화면으로 연결.
- 기존 index.html 은 손대지 않음.

## 스킬별로 한 일
- taste-skill: 방향 3개 중 "이름을 기념비처럼(name-as-monument)" 선택(seed 2001855683). 브랜드 색·서체는 그대로 두고(--keep) 배치만 받음.
  - 아이디어: "FnGuide 전용서체가 화면 가득한 움직이는 한 줄이 되고, FnRed 네모를 지날 때 흰 글자로 바뀐다."
  - 직접 해 보는 것 하나: 전용서체 화면에서 문구를 치면 그룹 색으로 바로 보이고 SVG·PNG 로 받기(기존 기능 유지).
  - 홈 순서: 첫 화면(움직이는 이름) → 브랜드 방향(오른쪽 절반 문단) → 사업별 컬러 띠(폭이 다른 색 면 6개) → 최근 업데이트(한 크기 글자 목록) → 바로가기 → 꼬리(어두운 바탕 + 큰 흰 로고).
- ui-ux-pro-max: 추천 스타일(유리 효과·금색·Inter/Playfair)은 브랜드와 맞지 않아 쓰지 않음. 점검표만 사용 — 글자 대비 4.5 이상, 키보드로 고른 곳 표시, 누르는 곳 44px, 움직임 줄이기 설정 존중, 375~1440px 폭 확인.
- impeccable: 마감 기준(eyebrow 금지, 그림자·테두리 이중 금지, 글자 선택색·스크롤바·포커스 색까지 브랜드 색으로) 적용, 다 만든 뒤 자동 검사(detect) 실행.

## 디자인 규칙(이번 시안)
- 색: 바탕 흰색, 한 단계 옅은 면 #F4F2F1, 글자 #1C1C3A, 강조 #B9023D(주요 단추·선택 표시에만). 사업 색은 사업 색 자리에만.
- 서체: 큰 제목·숫자는 FnGuide Logotype, 한글 본문은 Pretendard. 두 가지만.
- 모서리 각지게, 가는 구분선 대신 면의 밝기 차이로 구분(표 안은 예외).
- 로고는 어디서나 같은 배율(높이 맞춤 금지).

## 점검 결과 (2026-10-30)
- taste-skill 금지 패턴 검사(lint): 0건. 예외 표시 4곳 — 떠 있는 바·메뉴·알림의 그림자, 색 고르기 단추의 무지개색, 투명 배경 격자.
- taste-skill 화면 검사(inspect, 1440·768·390px): 남은 지적과 판단
  - 사진이 적음(홈 2~3장, 로고 화면 0장): 사내 자료 사이트라 남의 사진은 넣지 않음. 서체 점검 그림·애플 아이콘만 실제 그림으로 씀.
  - 첫 줄 제목이 가려짐·단어 수 많음: 흐르는 한 줄이 화면 끝에서 잘리는 것(의도).
  - 제목이 늦게 보임(서체·로고 화면): 한 파일 안에 화면 여러 개를 둔 구조 때문에 숨은 홈 제목을 먼저 읽는 것으로 보임.
  - 로고 화면 제목에 두 서체(B2B + 대표상품): 전용서체에 한글이 없어서(기존 사이트와 같음).
  - 휴대폰 서체 미리보기 옆으로 넘김: 긴 문구를 옆으로 넘겨 보는 기존 기능.
- impeccable 자동 검사(detect): 꼬리(어두운 바탕) 글자가 본문 아래 깔림 → 스크롤하면 드러나는 연출(의도). 흐르는 한 줄(의도). 투명 배경 격자(기능).
