# 04 — 디자인 아티클 서비스 고르기 개선 (2026-10-30)

## 사용자 요청
- "서비스를 선택하는 UI/UX가 불편해, 서비스가 많아질수록 더 나빠질 것 같아. 스킬을 이용해서 개선해줘."

## 스킬
- ui-ux-pro-max(ux 검색): 입력하는 대로 결과 보여 주기, 결과 없을 때 안내와 다음 행동, 고르는 단추는 진짜 단추 + 눌림 상태.
- impeccable(operate.md): 모달(화면 전체를 가리는 창) 대신 그 자리에서 펼치기, 펼친 판은 잘리지 않게, 짧은 움직임.

## 바뀐 것
- 기본 목록 상자(select) → 바의 "지금 서비스" 단추(작은 아이콘 + 이름 + 바꾸기). 누르면 바로 아래에 판이 펼쳐짐.
- 판: 찾기 칸(이름·그룹 이름·"심볼"로 찾음, 입력하는 대로 걸러짐, 개수 표시) + 그룹 단추(그룹별 개수, 결과 없는 그룹은 흐리게) + 그룹별 로고 타일(같은 배율, 고른 것은 FnRed 테두리, 심볼 있으면 "심볼").
- 타일에는 이름을 다시 쓰지 않음(로고가 곧 이름). "(개선 로고)"처럼 로고로 구별 안 되는 것만 덧붙임.
- 키보드: 열면 찾기 칸에 바로 입력, Enter = 이름이 찾는 말로 시작하는 첫 서비스, ↓ = 타일로, 화살표로 타일 이동, Esc = 닫기. 판 밖을 누르면 닫힘.
- 결과 없음: 찾는 말 + 예시 안내 + "찾기 지우기".

## 확인
- 헤드리스 크롬 1440·390px: 열기·찾기(펀드 → 5개)·결과 없음·Enter 고르기·그룹 좁히기·Esc 닫기 모두 동작, 스크립트 오류 0.
- 받기 13종 다시 확인: 파일 이름·크기 이전과 같음.

## 다시 고침 (사용자 요청: "검색 기능은 필요 없어, 심볼 표시는 옆에, 너무 많은 영역을 차지하지 않게")
- 찾기 칸·개수 표시·결과 없음 안내·Enter 고르기 삭제. 그룹 단추(그룹별 개수)는 유지.
- 그룹마다 한 줄: 왼쪽 그룹 이름, 오른쪽에 로고 타일을 이어 붙임(타일 높이 44px, 로고 배율 0.5 — 모두 같은 배율).
- "심볼"·"(개선 로고)"는 로고 아래가 아니라 오른쪽 옆에 작게.
- 열면 지금 고른 서비스 타일에 키보드 초점, 화살표로 이동, Esc·판 밖 누르기로 닫기.
- 판 높이: 넓은 화면에서 22개 전부 약 420px(이전 약 680px 넘어 스크롤), 휴대폰은 화면 70%까지 스크롤.
- 카드 크기 통일(사용자 요청): 전체 서비스 중 가장 긴 카드("FnGuide (개선 로고)", 179px) 폭에 모두 맞춤. 판을 처음 열 때 재서 기억. "심볼"·"(개선 로고)"는 카드 오른쪽 끝. 휴대폰은 두 칸으로 같은 폭.
- 아이콘(icon.ico)에 512px 추가(사용자 요청): 16·24·32·48·64·128·256·512 8개. 화면 미리보기에는 512px 를 그리지 않음(큼). 받은 파일을 열어 8개 크기 확인.
