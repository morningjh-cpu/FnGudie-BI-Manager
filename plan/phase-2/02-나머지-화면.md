# 02 — 리뉴얼 시안 나머지 화면 (2026-10-30)

## 사용자 요청
- 01의 B안 시안 확인 후 "진행해줘" → 나머지 화면도 같은 방식으로.

## 만든 것 (design-index.html 하나에 모두)
- 전용서체 하위 메뉴(탭): 서체 소개 #font · 폰트 업데이트 #font/update · 디자인 크리틱 #font/critique
- 로고타입 하위 메뉴(탭) 맨 끝에 "로고 받기" #download
- 디자인 아티클 #article · 사용 규칙 #rules
- 이제 기존 index.html 로 넘어가는 링크는 꼬리의 "기존 화면 보기" 하나뿐.
- 문구·수치·그림·받는 파일은 기존 화면과 같게 옮김. 바꾼 것은 모양뿐:
  - 로고 받기: 표 대신 그룹별 목록(줄마다 옅은 면 번갈아), 로고는 같은 배율(0.6) 그대로.
  - 디자인 아티클: 서비스 고르는 줄을 어두운 띠로, 화면 위에 붙어 따라오게(넓은 화면만).
  - 사용 규칙: 배경 조합을 색 면 위 흰 Fn + 흰 면 위 색 Fn 견본으로. 리타민 주·보조는 두 줄로 나눔.
  - 크리틱 등급: 꽉 찬 알약 대신 색 점 + 같은 색 글자(개선 권장 #9A5A00, 유지 #1A7049 — 흰 바탕 대비 4.5 이상으로 진하게).
  - 버전 이력: 표 대신 한 크기 목록.

## 확인
- 헤드리스 크롬으로 받기 단추 13종을 자동으로 눌러 파일이 만들어짐을 확인(스크립트 오류 0):
  로고 SVG·PNG·단색, 서체 미리보기 SVG·PNG, 전체 로고 ZIP, favicon.ico·icon.ico·PNG-512, 애플 PNG·기기별 ZIP, 오픈 그래프 PNG, 서비스 전체 ZIP.
- 전체 로고 ZIP(1,085,639바이트)·WiseReport 웹 아이콘 ZIP(136,923바이트)이 기존 index.html 에서 받은 것과 크기까지 같음.
- taste-skill lint 0건(— 사용 5곳 경고만). inspect 남은 지적은 01과 같은 종류(사진 적음·제목 늦게 보임·움직임 적음) + 표가 휴대폰에서 옆으로 넘어감(표는 넘겨 보게 둠).
- 확인 도구는 대화용 임시 폴더에만 있음(프로젝트에 넣지 않음).
